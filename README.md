# Polynomial Regression - Project Overview

This notebook demonstrates the use of **Polynomial Regression** to model non-linear relationships between features and the target variable. The dataset used is `Position_Salaries.csv`, which contains salary data corresponding to different position levels.

---

## 🔍 Objective

The goal is to compare **Linear Regression** and **Polynomial Regression** models in predicting salaries based on position levels. Polynomial Regression is particularly useful here due to the clear non-linear relationship between the variables.
